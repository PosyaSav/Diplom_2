# Diplom_2
## Задание 2. Автотесты для API

### Автотесты для проверки эндпоинтов API для Stellar Burgers
test_create_user.py - Создание пользователя:
    создать уникального пользователя;
    создать пользователя, который уже зарегистрирован;
    создать пользователя и не заполнить одно из обязательных полей.

test_login_user.py - Логин пользователя:
    вход под существующим пользователем;
    вход с неверным логином и паролем.

test_create_order.py - Создание заказа:
    с авторизацией;
    без авторизации;
    с ингредиентами;
    без ингредиентов;
    с неверным хешем ингредиентов.

### Структура проекта
tests - содержит файлы с тестами требуемых функциональностей 
conftest.py - файл содержит фикстуры 
data.py - файл содержит необходимые ссылки и данные для тестов
helpers.py - файл содержит наборы необходимых функций для генерации данных
